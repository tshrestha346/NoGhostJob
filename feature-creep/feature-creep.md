# Trade-offs and Feature Creep

## Ranking the features (useful to creep)
1. Job Posting (Job Creation)
2. White/Dark Mode
3. OTP-Based Login
4. One-Click Job Search with Multiple Filters
5. One-Click Job Application
6. Profile Editing
7. Rejection Feedback System
8. CV Creation Tool

## More Tension and Creep Feature

From the features we have added, **CV CREATION** would be a creep and tension lies there as building a CV creator requires significant development effort in areas such as templates, formatting, export handling, storage, editing UX, and possibly AI assistance. These resources might produce greater user value if invested in improving job recommendations, application tracking, or employer matching.
