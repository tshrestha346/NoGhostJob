# 📘 User Stories – No Ghost Job

This document outlines persona-based user stories for the **No Ghost Job** platform, focusing on solving inefficiencies in job searching, applications, and recruitment.

---

## 🔹 User Story 1: One-Click Job Search

### Actor: John (Job Seeker)


**User Story:**
> As a job seeker, I want to search for jobs using one-click filters, so that I can quickly find relevant opportunities without wasting time.

**Justification:**
Improves efficiency and reduces friction in job hunting.

---

## 🔹 User Story 2: One-Click Job Application

### Actor: Martha (Job Applicant)



**User Story:**
> As a user, I want to apply to jobs with one click, so that I can save time and increase the number of applications submitted.

**Justification:**
Reduces user fatigue and increases engagement.

## 🔹 User Story 3: Rejection Feedback System

### Actor: David (Job Seeker)

**User Story:**
> As a job applicant, I want to receive feedback on rejected applications, so that I can improve my chances in future applications.

**Justification:**
Addresses the “ghosting” problem and improves transparency.

## 🔹 User Story 4: CV Creation Tool

### Actor: Sofia (Student / Fresher)

**User Story:**
> As a user, I want to create a CV using guided templates, so that I can build a professional resume easily.

**Justification:**
Helps new users enter the job market effectively.

## 🔹 User Story 5: OTP-Based Login

### Actor: Alex (User)

**User Story:**
> As a user, I want to log in using OTP authentication, so that I can access my account securely without remembering passwords.

**Justification:**
Enhances security while simplifying login experience.
