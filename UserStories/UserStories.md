# 📘 User Stories – No Ghost Job

This document outlines persona-based user stories for the **No Ghost Job** platform, focusing on solving inefficiencies in job searching, applications, and recruitment.

---

## 🔹 User Story 1: One-Click Job Search

### Actor: Rahul (Job Seeker)

**Activity:**
- Searches for jobs using filters like location, role, and experience  
- Wants fast and relevant job listings  

**Problem:**
- Has to manually search across multiple platforms  
- Gets irrelevant or outdated job postings  

**Objectives:**
- Wants a centralized platform with accurate filtering  
- Needs quick access to relevant job opportunities  

**User Story:**
> As a job seeker, I want to search for jobs using one-click filters, so that I can quickly find relevant opportunities without wasting time.

**Justification:**
Improves efficiency and reduces friction in job hunting.

---

## 🔹 User Story 2: One-Click Job Application

### Actor: Ananya (Job Applicant)

**Activity:**
- Applies to multiple jobs daily  
- Uploads resume and fills forms repeatedly  

**Problem:**
- Time-consuming repetitive applications  
- High drop-off rate due to lengthy processes  

**Objectives:**
- Wants a fast and seamless application process  
- Avoid repetitive data entry  

**User Story:**
> As a user, I want to apply to jobs with one click, so that I can save time and increase the number of applications submitted.

**Justification:**
Reduces user fatigue and increases engagement.

---

## 🔹 User Story 3: Rejection Feedback System

### Actor: David (Job Seeker)

**Activity:**
- Applies for jobs but gets rejected frequently  
- Receives no feedback  

**Problem:**
- Doesn’t know why he is rejected  
- Cannot improve his profile or resume  

**Objectives:**
- Wants constructive feedback on applications  
- Needs guidance for improvement  

**User Story:**
> As a job applicant, I want to receive feedback on rejected applications, so that I can improve my chances in future applications.

**Justification:**
Addresses the “ghosting” problem and improves transparency.

---

## 🔹 User Story 4: CV Creation Tool

### Actor: Sofia (Student / Fresher)

**Activity:**
- Needs to create a resume for the first time  
- Has no experience in formatting  

**Problem:**
- Doesn’t know how to structure a professional CV  
- Uses poor templates  

**Objectives:**
- Wants guided resume creation  
- Needs professional-looking output  

**User Story:**
> As a user, I want to create a CV using guided templates, so that I can build a professional resume easily.

**Justification:**
Helps new users enter the job market effectively.

---

## 🔹 User Story 5: OTP-Based Login

### Actor: Alex (User)

**Activity:**
- Logs into job platforms frequently  

**Problem:**
- Forgets passwords  
- Faces login friction  

**Objectives:**
- Wants quick and secure access  
- Avoid password management issues  

**User Story:**
> As a user, I want to log in using OTP authentication, so that I can access my account securely without remembering passwords.

**Justification:**
Enhances security while simplifying login experience.

---

## 🔹 User Story 6: Profile Editing

### Actor: Maria (Experienced Professional)

**Activity:**
- Updates skills and experience regularly  

**Problem:**
- Profiles become outdated quickly  
- Misses relevant opportunities  

**Objectives:**
- Wants easy profile updates  
- Keep information current  

**User Story:**
> As a user, I want to edit my profile anytime, so that my job applications reflect my latest skills and experience.

**Justification:**
Ensures accurate and up-to-date user data.

---

## 🔹 User Story 7: Job Posting (Recruiter Side)

### Actor: Martha (Recruiter)

**Activity:**
- Posts job openings  
- Reviews applicants  

**Problem:**
- Uses multiple platforms  
- Hard to manage candidates  

**Objectives:**
- Wants a centralized hiring system  
- Easy applicant tracking  

**User Story:**
> As a recruiter, I want to post jobs and manage applicants in one platform, so that I can streamline the hiring process.

**Justification:**
Improves recruitment efficiency and platform usability.

---

## 🔹 User Story 8: Dark/Light Mode

### Actor: General User

**Activity:**
- Uses platform for long durations  

**Problem:**
- Eye strain in different lighting conditions  

**Objectives:**
- Wants comfortable UI experience  

**User Story:**
> As a user, I want to switch between dark and light modes, so that I can use the platform comfortably in different environments.

**Justification:**
Improves accessibility and user experience.
