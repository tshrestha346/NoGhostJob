# 📘 User Stories – No Ghost Job

This document outlines persona-based user stories for the **No Ghost Job** platform, focusing on solving inefficiencies in job searching, applications, and recruitment.

---

## 🔹 User Story 1: One-Click Job Search

### Actor: Rahul (Job Seeker)

**Activity:**
- Searches for jobs using filters like location, role, and experience  
- Wants fast and relevant job listings  

**Problem:**
- Has to manually search across multiple platforms  
- Gets irrelevant or outdated job postings  

**Objectives:**
- Wants a centralized platform with accurate filtering  
- Needs quick access to relevant job opportunities  

**User Story:**
> As a job seeker, I want to search for jobs using one-click filters, so that I can quickly find relevant opportunities without wasting time.

**Justification:**
Improves efficiency and reduces friction in job hunting.

---

## 🔹 User Story 2: One-Click Job Application

### Actor: Ananya (Job Applicant)

**Activity:**
- Applies to multiple jobs daily  
- Uploads resume and fills forms repeatedly  

**Problem:**
- Time-consuming repetitive applications  
- High drop-off rate due to lengthy processes  

**Objectives:**
- Wants a fast and seamless application process  
- Avoid repetitive data entry  

**User Story:**
> As a user, I want to apply to jobs with one click, so that I can save time and increase the number of applications submitted.

**Justification:**
Reduces user fatigue and increases engagement.
